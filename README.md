## English

**LotoBox** is a lightweight, offline-first Progressive Web App with an animated SVG lototron for hosting guaranteed-win lotteries at corporate events, exhibitions, and parties.

### ✨ Features
- 🎡 **SVG Animated Drum** — realistic spin with physics-based easing
- 📴 **100% Offline** — works without internet after first load
- 🎯 **Weighted Random** — probability proportional to remaining count
- 🌍 **Bilingual** — seamless Russian / English switching
- 📱 **PWA Ready** — installable on iOS, Android, Windows, macOS
- 🔒 **Hidden Admin** — discreet panel access for organizers
- ⚡ **Zero Dependencies** — pure Vanilla JS, instant loading
- 🔍 **SEO Optimized** — Open Graph, JSON-LD, semantic HTML

### 🚀 Usage
1. Visit [https://1r1shmann.github.io/lotobox/](https://1r1shmann.github.io/lotobox/)
2. First launch → Admin Panel → add prizes
3. Tap "To Lottery" → hand device to participant
4. Press **SPIN** → drum animates → confirm or cancel result

### 🛠 Self-Hosting
```bash
git clone https://github.com/1r1shmann/lotobox.git
cd lotobox && npx serve .
```

## Русский

**LotoBox** — легкая офлайн-система (PWA) с анимированным SVG-лототроном для проведения беспроигрышных лотерей на корпоративах, выставках и праздниках.

### ✨ Возможности
- 🎡 **SVG-барабан** — реалистичное вращение с физикой торможения
- 📴 **100% Офлайн** — работает без интернета после первой загрузки
- 🎯 **Честный рандом** — шанс пропорционален остатку призов
- 🌍 **Два языка** — мгновенное переключение Русский / English
- 📱 **PWA** — устанавливается как приложение на любое устройство
- 🔒 **Скрытая админка** — незаметный вход для организаторов
- ⚡ **Без зависимостей** — чистый JS, мгновенная загрузка
- 🔍 **SEO** — Open Graph, JSON-LD, семантический HTML

### 🚀 Использование
1. Откройте [https://1r1shmann.github.io/lotobox/](https://1r1shmann.github.io/lotobox/)
2. Первый запуск → Админка → добавьте призы
3. «К лототрону» → передайте устройство участнику
4. **КРУТИТЬ** → барабан крутится → подтвердите или отмените

### 🛠 Локальный запуск
```bash
git clone https://github.com/1r1shmann/lotobox.git
cd lotobox && npx serve .
```
